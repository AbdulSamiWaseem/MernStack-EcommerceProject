Full MERN Stack E-Commerce Project
This is a complete eCommerce application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) with separate Admin and Client sides. The project involves full API integration and management, ensuring smooth communication between the frontend and backend while handling user authentication, product management, order processing, and payment systems.

Key Features:
API Integration & Management: Comprehensive API integration across both the Admin and Client sides. The backend exposes RESTful API endpoints to manage data, such as products, users, orders, and payment processing.
Admin Panel: Admins can manage the entire eCommerce platform, including products, user accounts, and orders. Admin actions are controlled through API calls, ensuring real-time data updates.
Client Side: The client side interacts with the backend via APIs to browse products, manage the shopping cart, and proceed with checkout using Stripe payment integration.
State Management: The project utilizes Redux for efficient global state management on both the client and admin sides.
Form Handling: Formik and Yup are used for form management and validation, ensuring a seamless user experience.
Routing: React Router is implemented for smooth page navigation, enabling multiple routes for different user actions (e.g., product browsing, admin dashboard, checkout).
Responsive Design: The app is built to be fully responsive using Bootstrap, ensuring compatibility across various screen sizes.
Technologies Used:
Frontend: React, Redux, React Router, Formik, Yup, Bootstrap (for responsiveness), CSS
Backend: Node.js, Express.js, MongoDB (Mongoose)
API: Full API integration for product management, user authentication, order handling, and payment processing.
Authentication: JWT (JSON Web Tokens) for user authentication
Payment Integration: Stripe API for secure payments
This project is designed to provide a seamless, scalable, and secure eCommerce experience, with efficient API management ensuring smooth interactions between the frontend and backend.
