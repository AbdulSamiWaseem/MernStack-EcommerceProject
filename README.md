MERN Stack E-Commerce Project
This is a full-fledged eCommerce application built using the MERN stack (MongoDB, Express.js, React.js, Node.js) with separate Admin and Client sides. The project is designed to provide a seamless online shopping experience, with robust features and an intuitive interface.

Key Features:
Admin Panel: Manage products, users, orders, and more with an easy-to-use dashboard.
Client Side: Browse products, add them to the cart, checkout with Stripe payment integration, and track orders.
State Management: Efficiently manage application state using Redux for both client-side and admin-side functionalities.
Form Handling: Utilize Formik and Yup for form validation and management.
Routing: Implement React Router for smooth navigation across pages.
Responsive Design: Fully responsive layout built with Bootstrap, ensuring the application works seamlessly across different screen sizes and devices.
Technologies Used:
Frontend: React, Redux, React Router, Formik, Yup, Bootstrap (for responsiveness), CSS
Backend: Node.js, Express.js, MongoDB
Payment Integration: Stripe API for secure payments
This project is fully functional and optimized for both desktop and mobile devices, offering an interactive and user-friendly experience.
